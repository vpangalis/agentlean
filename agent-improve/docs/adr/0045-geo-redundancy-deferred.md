# 0045. Geographic redundancy is deferred

**Status:** PROPOSED (architecture sort, 2026-09-26)

**Source:** [ARCHITECTURE.md](../../ARCHITECTURE.md) §46.1, §68

## Context

A second region costs money before there are customers who need it.

## Decision

Single region until before launch; revisit with the DORA register.

## Consequences

A regional outage stops the service; recorded as a risk.
