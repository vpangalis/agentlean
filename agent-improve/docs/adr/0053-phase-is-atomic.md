# 0053. A phase is one atomic unit: schema, validator, skill

**Status:** PROPOSED (architecture sort, 2026-09-26)

**Source:** [ARCHITECTURE.md](../../ARCHITECTURE.md) §56.1

## Context

A phase built piecemeal left schemas without validators and skills without fields.

## Decision

A phase's schema, validator and SKILL.md land together.

## Consequences

Phases arrive complete or not at all.
