# Measure — product requirements (DRAFT — founder, 2026-09-26, to be completed)

> **Draft, not ratified.** Recorded verbatim; no feature cites it until the founder ratifies it.

M1 DATA UPLOAD WITH GUIDANCE
   As a Belt, I want the coach to show me, with a sample, how to conduct a
   measurement and how to shape my data file, so that it can recognise my
   data and calculate the KPIs correctly.
   Acceptance: before asking for data, the coach shows a demo file and
   explains each column (name, unit, meaning); after upload it states what
   it believes each column means and asks the Belt to confirm before any
   calculation; results name the columns they came from.
   Open: file types (Excel, CSV)? Maximum size? Which KPIs first?
