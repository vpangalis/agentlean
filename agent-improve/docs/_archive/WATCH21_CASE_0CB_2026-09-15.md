**Gzip rather than plain JSON, and the reason is that the content is opaque
either way.** Each body is `{"checkpoint_type": "msgpack", "checkpoint_data":
"<base64>", ...}` — base64-wrapped msgpack. Storing it uncompressed would put
650 KB of base64 in the tree and buy no readability, because nothing in it is
greppable and no diff of it is meaningful. It is an archive: it will never be
edited, only read whole. One file rather than 51 for the same reason — the
key is the original blob path, so nothing about the layout is lost.
